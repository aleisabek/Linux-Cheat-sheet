Linux & Bandit Quick Reference

Moving Around

Where am I?
pwd prints the current directory.
What is here?
ls lists visible items. ls -a also shows hidden items. ls -la adds details such as permissions, owner, and size.
Enter a folder
cd <folder> changes directory. Example: cd inhere.
Go up one folder
cd .. moves up one directory level.. means the current directory... means the parent directory.
Go to home directory
cd ~ or just cd takes you to your home directory.
Return to the last folder(Linux)
cd - switches to the previous directory.
Why doescat <folder>fail?
cat is used to display the contents of files, not directories. To view the contents of a directory, use ls.
